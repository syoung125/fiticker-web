# Fiticker

**건강한 일상을, 나만의 스티커로.**

이번 주 운동을 나만의 스티커로 만들고, 내 사진 위에 붙여 스토리를 꾸며보세요.
Fiticker는 가입 없이 무료로 사용할 수 있는 운동 기록 스티커 서비스입니다.

**[스티커 만들기](https://fiticker.com/weekly/)** · [서비스 둘러보기](https://fiticker.com/)

## 내 운동 기록이 스티커가 되는 순간

- **간편한 주간 기록** — 날짜를 골라 운동을 추가하고, 시간과 메모는 필요할 때 입력하세요.
- **운동마다 다른 메모** — 러닝 거리, 웨이트 부위, 클라이밍 완등 기록처럼 나에게 의미 있는 내용을 남길 수 있어요.
- **취향에 맞는 디자인** — 요약, 캘린더, 주간 기록 중 원하는 스티커를 고르세요.
- **사진에 어울리는 스타일** — 배경과 글자색, 시간 표시를 조절해 나만의 스티커를 만들어요.
- **복사하고 붙이기** — 완성한 스티커를 PNG로 복사하거나 저장해 스토리에 활용하세요.

## 이렇게 사용해요

1. 한 주의 운동을 기록해요.
2. 마음에 드는 스티커 디자인과 색상을 골라요.
3. 스티커를 복사하거나 저장해서 내 사진 위에 붙여요.

현재 웹에서는 기록을 브라우저에 임시 보관합니다. 새로고침해도 유지되지만, 탭을 닫으면 사라질 수 있어요.
